# Deploy dengan GitHub Pages

1. Buka repository GitHub yang sudah dipakai untuk OMNAS 4.2.
2. Pilih `index.html`, klik Edit atau Add file > Upload files, dan ganti dengan `index.html` versi 4.3.
3. Commit ke branch `main`. GitHub Pages (Settings > Pages) harus dipilih Deploy from a branch, branch `main`, folder `/(root)`.
4. Setelah deployment selesai, kunjungi situs dan refresh paksa (Ctrl+Shift+R, atau hapus cache situs).
5. Pastikan judul aplikasi bertuliskan 4.3 dan jumlah soal sesuai tabel README.

Jangan unggah ZIP secara langsung sebagai satu file ke repository; ekstrak dahulu dan unggah isi folder ke root.

**Perhatian:** GitHub Pages dengan repository publik dapat mengekspos bank soal OMNAS asli. Pastikan ada izin distribusi jika digunakan secara publik.
